Política de privacidad

Última actualización: 27 de noviembre de 2026

Esta política se aplica a la aplicación n8n, una automatización de uso exclusivamente personal creada por Iván Nieto Abarca para organizar su propio correo de Gmail. No está disponible para el público ni recoge datos de terceros usuarios.

Datos a los que accede

Con la autorización de su titular, la aplicación lee los correos de su propia cuenta de Gmail y les aplica etiquetas, los archiva, los marca como leídos o los mueve a la papelera.

Uso de los datos

El contenido de los correos se usa únicamente para clasificarlos y generar un resumen diario para el propio titular. Para ello, el texto se envía a la API de Google Gemini. Los datos no se venden, no se comparten con otros terceros y no se usan con fines publicitarios.

Almacenamiento

La aplicación se ejecuta en el equipo del titular. No guarda copias de los correos fuera de Gmail, salvo los registros técnicos temporales de cada ejecución.

Uso limitado de datos de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions.

Contacto

Para cualquier consulta, usa los datos de contacto de niet8.github.io.
